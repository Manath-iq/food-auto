# Своя кухня

Telegram Mini App для домашнего питания: рецепты → меню → список покупок → домашние запасы. Отдельный Cloudflare Worker `food-auto`, база D1 `food-auto-db`, ИИ — Gemini `gemini-2.5-flash-lite`.

Приложение: [food-auto.todominate-ai.workers.dev](https://food-auto.todominate-ai.workers.dev).

Бот: [@food_autotest_bot](https://t.me/food_autotest_bot). В боте нажмите **Старт**, затем **Своя кухня** или **Открыть свою кухню**.

## Что работает в первой версии

- 16 стартовых рецептов, поиск по названиям, ингредиентам и тегам; категории и комбинируемые фильтры.
- Избранное, личные заметки, собственные рецепты с автоматическим расчётом КБЖУ, редактирование, история приготовлений.
- Пересчёт ингредиентов по порциям, пошаговый режим и несколько таймеров.
- Меню на день и неделю, 6 приёмов пищи, несколько блюд на приём; порции, перемещение между приёмами, копирование дня и сохранённые шаблоны.
- Автоматические покупки на 1/3/7/14 дней или произвольный период; объединение одинаковых ингредиентов; вычет доступных домашних запасов.
- Ручные покупки, отметки о покупке, изменение количества, удаление и отмена; передача списка текстом.
- Перенос купленного в холодильник после подтверждения, сроки годности, заметки, списание ингредиентов при приготовлении.
- Подбор блюд по запасам: всё есть, не хватает до двух ингредиентов, больше совпадений.
- Gemini предлагает блюда, меню и новые рецепты. Сохранение предложений — только после подтверждения. КБЖУ новых рецептов считает приложение по ингредиентам.
- Проверенная сервером подпись Telegram, отдельные данные пользователей в D1, синхронизация, защита от перезаписи изменений другого устройства.
- Гостевой режим в браузере с сохранением на устройстве; ИИ доступен после входа через Telegram.
- Экспорт личных данных и удаление аккаунта из профиля.

## Запуск

Рекомендуется актуальный Node.js 26 LTS/current, совместимый с установленным `cf` (см. `engines` пакета); зафиксированные версии — в `package-lock.json`.

```sh
npm ci
cp .env.example .dev.vars
# Заполните .dev.vars локально — эти значения никогда не попадают в Git.
npx cf d1 migrations apply 9322e9a8-12ae-482c-8548-04ed519062a3 --local --persist-to .cloudflare/state --dir migrations
npm run dev
```

Локально: `http://127.0.0.1:5173`. Авторизация и ИИ проверяются в Telegram или локальным интеграционным скриптом с тестовыми подписанными данными. Боевой API не принимает неподписанные запросы.

```sh
npm run build
npm run typecheck
npm test
# Только localhost; создаёт и удаляет две тестовые учётные записи в локальной D1.
# Нужен локальный .secrets.json с BOT_TOKEN; --ai вызывает Gemini один раз.
node scripts/smoke-local.mjs http://127.0.0.1:5173 --ai
# Два дополнительных запроса: меню на два дня и новый рецепт; без сохранения черновиков.
node scripts/smoke-ai.mjs
```

## Публикация

```sh
npx cf auth login
npx cf d1 migrations apply 9322e9a8-12ae-482c-8548-04ed519062a3 --dir migrations
npm run deploy
```

Первая публикация выполнялась с `npx cf deploy --secrets-file .secrets.json`. Это игнорируемый локальный JSON с `BOT_TOKEN`, `GEMINI_API_KEY`, `WEBHOOK_SECRET`; секреты передаются в Cloudflare. При обновлении обычным `cf deploy` существующие серверные секреты сохраняются. Не добавляйте значения секретов в конфигурацию, workflow или клиентский код.

Для повторной настройки меню бота и webhook:

```sh
npm run bot:setup -- https://YOUR-WORKER.workers.dev
```

Команда устанавливает webhook с отдельным случайным секретом, команды бота и кнопку открытия приложения. Она не рассылает сообщения пользователям. Проверяйте результат `getWebhookInfo`.

GitHub Actions проверяет сборку, типы и тесты при push/PR. Отдельный workflow публикации запускается вручную; перед его использованием добавьте GitHub Actions secret `CLOUDFLARE_API_TOKEN` с доступом Workers Scripts Edit и D1 Edit к нужному аккаунту. Токены Telegram и Gemini уже хранятся в Worker; переносить их в GitHub не требуется.

## Данные и ограничения первой версии

- Стартовая пищевая ценность — приблизительные справочные значения для сырых ингредиентов. Это не проверенная диетологом база. Все расчёты и ориентировочные цены помечены как оценки. Вес готового блюда можно указать в собственном рецепте; без него расчёт на 100 г относится к исходным ингредиентам.
- Фотографии Pexels — иллюстрации, не подтверждение точного состава рецепта. [Источники фотографий](docs/assets.md).
- Начальный справочник содержит 43 продукта с едиными идентификаторами. Новые рецепты используют этот справочник, что предотвращает дубли и несовместимые единицы измерения.
- В этой версии хранится ограниченный JSON-документ пользователя с номером ревизии. При одновременном редактировании на двух устройствах конфликт показывается явно; предлагаются выгрузка локальной копии и загрузка серверной версии. Это защищает от тихой потери данных.
- На бесплатном [тарифе Gemini](https://ai.google.dev/gemini-api/docs/pricing) действуют квоты Google; приложение дополнительно ограничивает запросы: 15 на пользователя и 200 на приложение за сутки UTC. Автоматического перехода на платную модель нет. Тариф и биллинг самого Google-проекта управляются владельцем ключа.
- Gemini получает только запрос и кулинарный контекст без имени/Telegram ID. Бесплатный Gemini может использовать данные для улучшения моделей — это указано в интерфейсе и `/privacy`.
- ИИ в первой версии предлагает новое меню и новые рецепты; изменение/удаление уже сохранённых данных выполняется вручную. Автоматическое изменение чужих данных невозможно.
- Таймеры показывают оставшееся время, пока приложение открыто; фоновые уведомления не гарантируются.
- Ссылки на встроенные рецепты открывают публичный каталог. Личные рецепты передаются текстом с ингредиентами и шагами; они не становятся публичными в каталоге.

## Следующие этапы из ТЗ

Исходное ТЗ сохранено в [docs/technical-spec.txt](docs/technical-spec.txt). Первая поставка закрывает MVP и основные связи корзины/холодильника/ИИ; весь список будущих возможностей не выдаётся за реализованный.

- Распознавание продуктов и рецептов по фото, прямые загрузки фотографий в R2, генерация изображений блюд.
- Управляющие действия ИИ: замена конкретного блюда, переносы и изменения запасов/покупок с отдельными подтверждаемыми предложениями.
- Полная административная панель с управлением рецептурой, нутриентной базой, модерацией и статистикой.
- Семейное пространство, приглашения и общий доступ, совместное редактирование списка по ссылке.
- Уведомления бота по выбранному расписанию, фоновое напоминание таймеров.
- Проверенная расширенная база нутриентов, индивидуальные цены на продукты, дополнительные единицы и способы приготовления.

## Архитектура

`src/` — React + TypeScript, адаптивный интерфейс; `src/domain.ts` — единые расчёты; `worker/` — API, проверка Telegram, Gemini, webhook; `migrations/` — таблицы и стартовый каталог; `tests/` — проверка бизнес-логики и авторизации. У сохранённых блюд в меню есть снимок рецепта: изменения в библиотеке не меняют уже запланированные блюда.

Официальные руководства: [Cloudflare Workers](https://developers.cloudflare.com/workers/), [Cloudflare CLI](https://developers.cloudflare.com/cf/), [Telegram Mini Apps](https://core.telegram.org/bots/webapps), [Gemini structured outputs](https://ai.google.dev/gemini-api/docs/structured-output).
