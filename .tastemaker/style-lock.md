# Style lock — Своя кухня

Дата: 31.10.2026. Источник: пять изображений, приложенных Максимом в текущем запросе. Статус: композиция и уточнённая эвкалиптовая палитра приняты Максимом 31.10.2026 при команде commit/push. Текущая просьба о редизайне имеет приоритет над прежним светлым интерфейсом.

## Направление

Ежедневное мобильное приложение для домашней готовки. Режим: Operate. Тёплая еда, спокойный тёмный фон, крупные округлые формы. Вариативность 5/10, движение 3/10, плотность 5/10, арт-направление 7/10.

Первый экран: название, короткий заголовок, поиск, категории, блюдо дня и лента. Основные риски: мелкий текст и длинные названия на 320 px, фото и призыв в акцентной карточке, перекрытие нижней панелью. Базовый стек сохранён: React, CSS/Tailwind 4, Phosphor, Motion; нативный dialog. Новые зависимости не добавлены.

## Точные правила

- Все токены — `src/tokens.css`; человекочитаемое описание — `docs/design-system.md`.
- Фон #191d1c; поверхность #252b28; зелёный #b2cdbc; текст #f1f0e9; подписи #b0b8b2.
- Светлые карточки #efece2, #e4d3c4, #d1dfd7; текст #26322c; подписи #4c5c52.
- При уточнении палитры подписи карточек #4c5c52 проверены на овсяной поверхности #e4d3c4: 4.87:1.
- Основная кнопка: #202b26 на #b2cdbc, 8.61:1. Белые подписи на зелёном не применять.
- Матрица: `docs/design-contrast.txt`. Основной/вторичный текст допустим на фоне и тёмных поверхностях; на светлых карточках только `--on-card` и `--card-muted`. Hairline #404b45 декоративный, для фокуса — зелёный. Семантические предупреждения на тёмных поверхностях с текстовым объяснением.
- Единственная тема — тёмная. Пользователь пока не просил переключение тем.
- Manrope, кириллица, системный fallback; заголовки 750–800, UI 600–700, текст 400–500. Основной текст 14–16 px. Поля 16 px, данные 12 px. Цифры табличные.
- Шаг интервалов 4 px, основные 12/16/20/24/32/40. Плотность приложения, без отступов лендинга.
- Радиусы 12/24/32 px; карточка рецепта 28 px; действия и навигация в капсулах. Тени только у навигации, окна и фото акцентного блюда.
- Пять нижних пунктов на мобильном, выбранный — зелёная капсула и `aria-current`. Desktop sidebar с 1100 px.
- Фото: существующие Pexels в `public/images`, источники `docs/assets.md`. Знак кастрюли и название сохранены, favicon создан из того же Phosphor CookingPot. Иллюстрации не требуются для пищевого каталога.
- 140 мс нажатие, 200–220 мс окно/позиция, cubic-bezier(.22,1,.36,1). MotionConfig reducedMotion=user + CSS reduced-motion. Блик загрузки 1.6 с — повторяющийся статус ожидания.

## Проверки и решения

Механический anti-slop scan пройден. Motion audit: предупреждения о reduced-motion покрыты общим MotionConfig; 1.6 с относится к индикатору загрузки. Итоговые результаты проверки сборки, типов и браузера см. в отчёте по задаче.

Личные priors отсутствуют: `~/.tastemaker/profile.md` не найден. Профиль не создан и не изменён. Журнал `.tastemaker/decisions.log` фиксирует положительную оценку композиции и принятие уточнённой палитры 31.10.2026. История предыдущих вариантов сохранена.

## Не делать

Не превращать мобильный экран в уменьшенный desktop. Не использовать белый текст на зелёной кнопке, массовые подписи 7–9 px, плавающие тени у каждой карточки, несколько разных наборов иконок, вступительные анимации при каждом действии.
